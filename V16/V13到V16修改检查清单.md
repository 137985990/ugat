## 常见问题与解决方案

### 问题1：NameError: name 'input_classifier' is not defined
**解决方案**：确保在函数参数中添加了input_classifier和reconstructed_classifier

### 问题2：KeyError in checkpoint loading
**解决方案**：检查点恢复时使用if判断：
```python
if 'input_classifier_state_dict' in checkpoint:
    input_classifier.load_state_dict(checkpoint['input_classifier_state_dict'])
```

### 问题3：梯度裁剪失败
**解决方案**：确保all_params包含所有模型参数：
```python
all_params = list(model.parameters())
if input_classifier is not None:
    all_params.extend(input_classifier.parameters())
```

### 问题4：CUDA内存不足
**解决方案**：两个分类器增加了参数量，可能需要：
- 减小batch_size
- 使用混合精度训练
- 增加梯度累积步数
